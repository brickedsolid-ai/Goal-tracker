# Reign - Daily goals tracker
A daily goals tracker built with Vite, React, and TypeScript.

## Features
- Create, edit, archive, and restore daily goals
- Checkbox and timed goals with minute logging
- Today progress, streaks, completion, and optional daily notes
- Goal history with current and best streaks plus total time
- Seven-day Insights chart and goal breakdown
- Responsive mobile-friendly UI
- IndexedDB persistence via idb; no login required

## Run locally
Install dependencies, then start the Vite development server.
npm install
npm run dev
npm run build

Data stays in this browser. Clearing site data clears goals and logs.
